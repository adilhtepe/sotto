Get started

VBAN audio, sotto voce.

An open toolkit for VBAN network audio: a zero-allocation C SDK, virtual sound cards for Windows, macOS and Linux, and an OpenWrt hub with an eBPF fast path. Encrypted when you want it, even across the internet.

One protocol, every platform

Use the SDK on its own, or let the hub route streams between Voicemeeter, phones, computers and microcontrollers.

C99 SDK

Send, receive and mix on anything with a C compiler

Lock-free jitter buffer with clock-drift resampling, a matrix mixer, PING0 discovery and RT packets. Runs on Linux, Windows, macOS, Android, ESP32 and Arduino.

// 64 frames per packet: 1.33 ms of audio at 48 kHz

OpenWrt hub

A router that routes audio

Fan-out, renaming and volume in LuCI. A tc eBPF fast path forwards inside the kernel.

Sound cards

Virtual sound cards

“Sotto Out” and “Sotto In” on Windows, macOS and Linux (ALSA and PipeWire). Pick them in any app and the audio goes over the network.

Kotlin

Android, without the glue

A 128 KB library for four ABIs. read() fills your audio callback straight from the jitter buffer, with no copy and no allocation.

Encrypted when it matters

Plain VBAN trusts every packet on the LAN. Secure VBAN gives each device its own key and a certificate from a CA that lives on your router. It also carries audio across the internet, through NAT.

Audited crypto. Monocypher, vendored unmodified. Noise XX handshake, ChaCha20-Poly1305 on every packet.

Routes follow certificates. A spoofed IP address gets nowhere; revoking a device ends its session at once.

Voicemeeter keeps working. The hub decrypts and forwards to plain receivers, so you can secure one device at a time.

Start with a tone

Build the SDK, play a test tone in one terminal and listen in another. Swap the receiver for Voicemeeter or the hub when it works.

bash
# get the code
$ git clone https://github.com/adilhtepe/sotto-sdk && cd sotto-sdk
$ cmake -S . -B build && cmake --build build -j
# listen on 6980 and play through ALSA
$ ./build/vban_recv -n Stream1 | aplay -f S16_LE -r 48000 -c 2
# in a second terminal: a 440 Hz tone, 64 frames per packet
$ ./build/vban_send -i 127.0.0.1 -n Stream1 -b 64

Going secure

vban_cert makes the CA, device keys and certificates. Add --ca, --cert and --key to send and receive.

On the router

deploy.sh installs the hub and its LuCI page. The Security tab creates the CA and signs devices.

As a sound card

Windows, macOS and Linux each have a driver in their own repository. Pick “Sotto Out” as the output and you are sending VBAN.

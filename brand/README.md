# Sotto brand files

|---|---|
| `sotto-mark.svg`, `sotto-mark-512.png` | The mark alone: avatars, favicons, app icons |
| `sotto-logo.svg` / `.png` | Mark and wordmark, for light backgrounds |
| `sotto-logo-dark.svg` / `.png` | Mark and wordmark, for dark backgrounds |

| `sotto-linkedin-1080.png` | Square post image |

Colours: teal `#0F6E56`, mint `#9FE1CB`, ink `#12201C`, night `#0C1311`. The wordmark is Geist Bold (SIL OFL), converted to outlines.
